# Phase I — Equipment and Training Decisions

**Status:** Decisions recorded from the product discussion; implementation details and the open questions below still need design. This document refines the [Phase I plan](plan.md) and [working use cases](use-cases-and-equipment.md).

## Places and equipment

- A user can create multiple private places and later select multiple gyms. Places form a list. A workout plan/unit is associated with one gym when a place is selected; using the same plan at a different gym means creating a separate plan. The place for a session is known before it starts and does not change during the session. Using a place remains optional.
- A private place has a name and may have an address and description. Copying places is deferred. Private users add as much equipment as they want; later, gyms maintain their own public equipment catalogs. Private data can be incomplete and entered gradually.
- Equipment has a name and optional description and photo. Include one equipment photo per item in Phase I for testing, including private places. Similar machines are separate items. Start with an empty inventory and add items by type. Photo storage, backup representation and limits still need design.
- Suggest common bar presets such as 20 kg and 10 kg, with a custom option. The shared place inventory stores available plate denominations, without quantities; calculations assume sufficient plates of each listed denomination. This is an assumption, not confirmation of real-time availability. Assume symmetric bar loading for automatic calculations, prefer an arrangement with fewer plates, and exclude collar mass.
- Record fixed dumbbell and kettlebell weights and quantities. Let users choose whether a dumbbell entry refers to one dumbbell or a combined load. Adjustable dumbbells may be modeled like small bars with a known handle mass and compatible plates; additional plates can be entered. Adjustable kettlebell settings can be entered as a list. Exact compatibility and loading rules remain open.
- Stack settings may be generated from a range and increment and then edited for irregular values. Plate-loaded machines distinguish a shared loading point from separate sides. Unknown starting load remains unknown; record plate load without inventing total resistance. For independent stacks or sides, manual recording is acceptable initially; automatic support can be considered later.

## Exercises and plans

- Machines are distinct equipment items. An exercise may reference a specific machine and its settings, but this is optional. Multiple exercises can refer to the same machine; independent exercises can have the same name while referring to different machines. Exercise-specific and equipment-specific settings must be distinguished during design.
- A local exercise collection supplies exercises to workout units. Reusing the same exercise in multiple units shares its settings, history and progression; an independent exercise can have the same name and machine but different settings and its own history. Creating a copy copies settings and notes but starts an independent empty history. Exercises on different machines are independent; changing the machine creates an independent version. Separate place-specific units can use appropriately configured independent exercises.
- Machine properties such as name, photo, description and available weights belong to the machine; exercise name, persistent technical note and personal machine settings belong to the exercise; performed weights, equipment and session notes belong to the workout. The previous assumption that set ranges and progression settings are always independent per plan occurrence is superseded by the shared exercise settings decision; the detailed split of other plan-specific settings remains to be designed.
- No special occupied-machine or wrong-gym workflow is required by the current decision. Users may save workout changes to a personal plan when they choose; the exact interaction with equipment substitution needs clarification.
- A user has a default weight-entry convention and can choose a convention for an exercise. Total, both sides of plates, and one side are supported for barbells; suggestions are displayed in the selected convention, with a plate arrangement corresponding to it. Showing a calculated equivalent is desirable where reliable, but its placement is not a priority. Manual entries remain allowed even when inventory does not confirm the load.

## Warm-up and progression

- Users can manually add and configure warm-up sets per exercise, including percentages and repetitions. Suggested counts are specified below; percentage presets and repetition interpolation are proposals in the calculation examples. Warm-up tasks are not saved to completed history. Completed tasks can be unchecked; visibility depends on the workout view. Recording the first working set automatically marks unchecked tasks complete; undoing that working set does not automatically undo them. State persists during an interrupted active session. Warm-ups are excluded from progression and statistics.
- Warm-up targets use the planned first working-set weight. For a new exercise the user can enter that weight before starting to obtain suggestions, or enter warm-up values manually. Changing the working weight during the exercise does not automatically recalculate the current warm-up suggestions; remaining sets can be edited manually and the changed weight informs the next workout's suggestions. Completed warm-ups are not changed retroactively.
- Users choose a progression method per exercise: available plates, available machine weights, or a custom increment. Plate-based progression uses the smallest feasible increase based on listed plate denominations and loading rules; machine-based progression uses the next available machine weight. Custom progression requires an entered increment and does not rely on either equipment-based method. If an equipment-based method lacks data, explain what is missing and offer to complete it, switch to a custom increment, or enter weight manually. Do not introduce a separate large-jump threshold.
- At the upper repetition limit, propose the next weight under the selected method and reset repetitions to the lower limit; both remain editable. Base later suggestions on the actually recorded result rather than the previous suggestion. Below the upper limit, including below the lower limit, suggest the same weight and one more repetition: for a range of 8–12 and six recorded repetitions, suggest seven. The lower limit is used when resetting repetitions after increasing weight.
- If no higher machine weight exists, inform the user and allow manual entries or switching to a custom increment, for example when they arrange additional load themselves; do not claim this custom load is a listed machine setting. A future profile badge or other gamification is an idea for a later phase, not an MVP requirement. Progression remains independent per working set: match the first set to the previous first, the second to the previous second, and so on. A new set with no previous counterpart has no imposed suggestion; a user may enter or copy a value. Removed sets remain in history.
- Treat same-named exercises configured for different machines as independently created exercises where the user chooses that arrangement; do not assume machine loads are equivalent.

## History and future coaching

- Show the selected place and equipment in history when available. Keep the historical place and equipment names when those items are renamed or deleted. The separate rule for shared exercise renaming remains in the product specification.
- Removing an exercise from a unit removes its association only, leaving the exercise in the collection and other units. Deleting it from the collection removes it from all units; offer either preserving its history or deleting its results from completed workouts, with explicit confirmation for history deletion. Other exercises in those workouts remain. Renaming a shared exercise updates its displayed name in history, without changing recorded values or equipment.
- In the future coaching phase, agreeing to connect with a coach shares the trainee's equipment inventory. This decision concerns equipment; existing restrictions on workout history, body weight and personal plans continue to apply. Exact scope, withdrawal and relationship termination behavior require design.

## Further decisions: model review

- Exercise ordering belongs to each workout unit. The same exercise cannot appear twice in a unit; create an independent copy instead. Changing a machine creates an independent version and leaves the original available.
- During a workout, changes are session-only unless the user elects to save them; before saving changes to a shared exercise, show that all units using it are affected. Exact treatment of different kinds of changes requires design.
- A unit without an assigned place can be used with no place. Phase I excludes a separate quick workout without a plan; users start sessions from workout units.
- Equipment descriptions and photos are optional; support one photo per item in Phase I. Full backup includes photos. If photos are corrupt during import, inform the user and allow a decision about importing without them; create a backup of the current state before replacement.
- Removing a machine leaves exercises in place with an indication that the equipment is unavailable; history retains the previous machine name. Before deleting a place, show affected units and exercises; after confirmation units lose their place and exercises remain with missing equipment indicated. Completed history retains place and equipment names.
- A gym supplies the available plate denominations; an exercise can use all or a selected subset. Two adjustable dumbbells are assumed to have the same load for automatic suggestions; asymmetric entry requires further design.
- Warm-up tasks automatically marked complete can be unchecked. Their completion state is not part of completed history; exercise configuration remains. After completion, editing history does not reopen warm-up tasks. For the next workout the suggested first working-set weight, informed by the actual previous result and progression, can be used as the warm-up basis, and the user may change it.
- A custom progression increment is configured per exercise. Users can change progression method without copying the exercise; history remains and the next suggestion uses the actual last result. If a manually recorded barbell weight cannot be reproduced using the selected plates, suggest the nearest feasible higher weight without altering the recorded result.
- Correcting a historical result affects future suggestions, and deleting the latest session makes the previous applicable result the basis.
- An exercise references current equipment data for future use, so equipment updates are available to it. An active session retains equipment data from its start; later catalog changes apply to subsequent sessions. A user can still enter an actual weight manually if a denomination was omitted. Completed sessions retain the recorded load, its meaning, and historical place and equipment names as they were at the time; changes or deletions of equipment do not rewrite them.
- An independent exercise copy initially refers to the same equipment and its photo; it does not duplicate the machine or image. The copied exercise has its own settings and empty history.
- Block deletion of an exercise, equipment item or plan used by an active workout until it is finished or cancelled. If removing an exercise's history leaves a completed session empty, ask whether to delete the empty session or keep its date and note.
- Calculation conventions and the user's proposed warm-up guidance are documented in [weight calculation examples](weight-calculations.md). Guidance ranges are design input until exact editable presets and timer behavior are agreed.
- When proposing warm-up set counts, compare the exercise's primary muscle group with earlier exercises in the unit. For a later exercise for the group or an isolation, suggest one set, which the user can remove. Otherwise use first working-set target repetitions: 1–5 → four sets, 6–8 → three, 9–11 → two, 12+ → one. Round calculated repetitions up, with a minimum of one. Show suggested rest during warm-up without automatically starting its timer. Fixed percentage presets and a proposed repetition calculation are documented in the [calculation examples](weight-calculations.md) for review.

## Questions to resolve

1. When a plan has no associated place, how is the optional place chosen before a session?
2. How are optional photos stored, included in backup and limited?
3. How is compatibility of selectable plate denominations with adjustable dumbbells represented?
4. Which settings, if any, remain specific to a plan occurrence alongside the shared exercise settings?
5. How does the user change progression methods in the interface, including when equipment data is incomplete?
6. Which final warm-up presets and repetitions should be suggested for each number of sets? How should the completed warm-up state be discarded on finishing a session?
7. What exactly is shared with a coach when a relationship is accepted, and can equipment sharing be separately withdrawn?
